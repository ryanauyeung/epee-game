# 重劍（épée）反應訓練小遊戲

單檔瀏覽器遊戲：內嵌 CSS／JS，無外部資源。背景為香港啟德體育園主場館。

## 怎麼玩

用瀏覽器直接打開 `epee.html`（或 `index.html`，內容相同）。

- 模式：正規局（先到 5 分或 3 分鐘結算）／生存模式
- 難度：初學／普通／高手
- 操作：A／D 或方向鍵移動；J／Z 輕刺、K／X 重刺、L／C 假動作、S／; 格擋

## 專案檔

| 檔案 | 說明 |
|------|------|
| `epee.html` | 可玩原型（canonical） |
| `index.html` | 與 `epee.html` 相同，方便靜態託管預設入口 |
| `SPEC.md` | Product & UX 規格 |
| `SMOKE.md` | Indie Full-stack 冒煙紀錄 |
| `ACCEPTANCE.md` | Review & QA 驗收（2026-10-05 PASS） |
